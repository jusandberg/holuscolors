# Changing icons on the hōlus. test site

1. Open **icons.html** on the site (jusandberg.github.io/holuscolors/icons.html) to see every icon and its file name.
2. On GitHub, open the page you want to change:
   - Home: `index.html`
   - About: `about/index.html`
   - Services: `nutritional-counselling/index.html`
   - Approach: `nutrition-behaviour-change/index.html`
   - Digest: `digest/index.html`
3. Tap the pencil to edit. Use your browser's find (Ctrl+F or Cmd+F) to find the old icon's file name.
4. Replace only the name part, for example change `drink-smoothie.svg` to `food-mango.svg`. Keep the folder part (`../assets/illustrations/`) the same.
5. Tap **Commit changes**. The site updates in a minute or two.

To add a new icon, upload the .svg file into `assets/illustrations`, then use its name the same way.
